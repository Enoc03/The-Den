#  The Den – Combat Sports & Training Website

## About the Project

The Den is a simple, responsive website designed for a combat sports and martial arts training facility. The website introduces visitors to The Den, showcases the different training options available and allows interested individuals to submit an enquiry to find out more about training.

The website uses a black and gold theme to reflect The Den's branding and create a bold, modern look that suits a combat sports facility.

## Features

- **Homepage:** Introduces The Den and highlights the facility.
- **Muay Thai Page:** Provides information about Muay Thai training.
- **Kickboxing Page:** Introduces kickboxing training.
- **Personal Training Page:** Showcases personalised training enquiries.
- **Booking & Enquiry Form:** Allows visitors to submit their contact details and training interests.
- **Navigation Bar:** Provides navigation between the different pages.
- **Responsive Design:** Adjusts the layout for desktop, tablet and mobile screens.
- **Black & Gold Theme:** Consistent styling throughout the website.
- **Training Information:** Dedicated pages with information about each training option.

## Technologies Used

- HTML5 – Used to structure the website.
- CSS3 – Used for styling, layouts and responsive design.
- JavaScript – Used to automatically select the training interest on the enquiry form based on the selected page.

## Getting Started

### 1. Download or Clone the Repository

Download the project or clone it from GitHub.

### 2. Open the Project

Open the project folder in Visual Studio Code.

### 3. Check the Images

Make sure all images are inside the `images` folder and their filenames match the references used in the website.

### 4. Run the Website

Open `index.html` in your browser or use the Live Server extension in Visual Studio Code.

## Booking & Enquiries

The booking page includes a form where visitors can provide their:

- First and last name
- Email address
- Contact number
- Training interest
- Preferred contact method
- Additional information

The form is designed to allow The Den to contact interested visitors regarding their enquiries. Form submission functionality requires a form service to be connected.
